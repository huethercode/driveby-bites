How Roadside Telemetry Works

Capture at 45 MPH, Verify When Parked

1. Real HTML5 Geolocation + Fallback

Tapping the green button requests your phone's high-accuracy GPS coordinates (navigator.geolocation) and compass heading. If tested on a desktop without GPS, it generates a realistic Chicagoland corridor pin so you can test the full workflow.

2. Hands-Free Web Speech Dictation

Tap Dictate Voice Note to speak what caught your eye (e.g., "Peruvian rotisserie chicken in the corner strip mall"). Your phone transcribes it directly into the pin record.

3. 1-Tap Google Maps Strip-Mall Lookup

Later, open the Capture Inbox and tap Verify on Google Maps. It opens Google Maps centered on your exact captured coordinates at zoom level 17z so you can immediately identify the storefront name, rating, and review count.

GitHub Pages 3-Minute Deploy SOP

Host Free & Install on Android

  1. Create a new public repo on github.com named driveby-bites.
  2. Click Add file → Create new file, name it index.html, paste this file's HTML, and commit.
  3. Go to Settings → Pages, set Source to Deploy from a branch (main / /root), and click Save.
  4. Open https://<username>.github.io/driveby-bites/ in Chrome on Android.
  5. Tap ⋮ → Add to Home screen / Install app for a full-screen native-style icon!
